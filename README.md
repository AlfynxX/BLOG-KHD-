# Pramuka KHD Website

Official website project for Pramuka KHD (Ki Hajar Dewantara).

This project represents the organization’s identity and values in a clean, structured, and professional digital format, aligned with the principles of character building, discipline, leadership, and creativity.

Project Overview

The website serves as an official digital representation of Pramuka KHD and is designed for clarity, consistency, and long-term maintainability.

Concept & Development

All concepts, ideas, structure, and content direction were fully created by the author.

AI assistance (Lovable) was used only as a supporting tool to refine language and improve technical execution.
The core vision and concept remain entirely original.
